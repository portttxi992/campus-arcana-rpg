# 校園奧秘 (Campus Arcana)

現代 + 校園 + 奇幻 文字RPG 完整系列

## 章節
1. **校園奧秘I・轉學生的覺醒** — 轉學第一天，揭開秘密
2. **校園奧秘II・影之侵蝕** — 第一場真正的危機
3. **校園奧秘III・裂隙真相** — 舊守門人現身，真相浮現
4. **校園奧秘IV・終焉之選** — 最終抉擇，多結局

## 功能
- 動態標題（選擇章節後標題會改變）
- 章節解鎖系統（必須從第一章開始，完成後解鎖下一章）
- 標題畫面背景音樂（Web Audio 環境音，可開關）
- 好感度系統優化（顯示等級：陌生→認識→友好→信賴→親密→羈絆 + 愛心）
- 只顯示已登場角色的好感度
- 本地存檔 / 讀檔
- 隨機三字暱稱

## 遊玩方式
1. 開啟 GitHub Pages（Settings → Pages → Source: main / root）
2. 訪問 https://portttxi992.github.io/campus-arcana-rpg/
3. 建議從「開始新遊戲」進入第一章
4. 完成一章結局後自動解鎖下一章

## 注意
- 舊存檔可能不相容，建議清除瀏覽器 localStorage 後重新開始
- 音樂為瀏覽器生成的環境音，無需額外檔案
