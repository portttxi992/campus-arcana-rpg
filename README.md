# 校園奧秘 (Campus Arcana)

現代 + 校園 + 奇幻 文字RPG

## 目前章節
- **校園奧秘I・轉學生的覺醒**：轉學第一天，揭開星辰高中的秘密
- **校園奧秘II・影之侵蝕**：加入守門人後的第一場實戰危機

## 如何遊玩
1. 開啟 GitHub Pages（Settings → Pages → Source 選 main branch / root）
2. 訪問 `https://portttxi992.github.io/campus-arcana-rpg/`

## 功能
- 玩家自訂名稱或隨機三字暱稱
- 選項推進劇情（劇情向）
- NPC 好感度系統（只顯示已登場角色）
- 本地存檔 / 讀檔
- 可選擇不同劇情版本
- 可擴充劇情框架

## 擴充新劇情
1. 在 `STORY_PACKS` 註冊新章節
2. 新增對應的 `CHAPTERx_STORY` 物件
3. 在 `loadStory` 加入判斷
